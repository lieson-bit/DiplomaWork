# Driver Service API Summary

## 📊 **Service Overview**
**Port:** 3002  
**Health Check:** `GET /health`  
**API Documentation:** `GET /api/docs`  
**OpenAPI Docs:** `GET /api-docs`  

## 🔐 **Authentication**
All endpoints require JWT Bearer token authentication:
```
Authorization: Bearer <jwt_token>
```
User must have `userType: 'driver'`

---

## 📋 **API Endpoints**

### **1. Driver Profile Management**
#### `POST /api/drivers/profile`
**Creates a driver profile**
```json
{
  "licenseNumber": "DL1234567890",
  "licenseExpiry": "2025-12-31",
  "insuranceNumber": "INS9876543210",
  "insuranceExpiry": "2024-12-31"
}
```

#### `GET /api/drivers/profile`
**Retrieves complete driver profile**
```json
Response:
{
  "success": true,
  "data": {
    "id": "uuid",
    "userId": "user_uuid",
    "licenseNumber": "DL1234567890",
    "licenseExpiry": "2025-12-31T00:00:00.000Z",
    "insuranceNumber": "INS9876543210",
    "insuranceExpiry": "2024-12-31T00:00:00.000Z",
    "rating": 4.5,
    "totalDeliveries": 150,
    "totalEarnings": 4500.75,
    "completionRate": 95.5,
    "status": "active",
    "verificationLevel": "verified",
    "onboardedAt": "2024-01-15T10:30:00.000Z",
    "isOnline": true,
    "currentLocation": "40.7128,-74.0060",
    "profileCompleted": true,
    "user": {
      "id": "user_uuid",
      "email": "driver@example.com",
      "firstName": "John",
      "lastName": "Doe",
      "phone": "+1234567890"
    },
    "vehicles": [...],
    "documents": [...],
    "profilePicture": {...},
    "availability": [...]
  }
}
```

#### `PUT /api/drivers/profile`
**Updates driver profile**
```json
{
  "licenseNumber": "DL9876543210",
  "licenseExpiry": "2026-12-31",
  "insuranceNumber": "INS1234567890",
  "insuranceExpiry": "2025-12-31",
  "currentLocation": "40.730610, -73.935242"
}
```

### **2. Profile Picture Management**
#### `POST /api/drivers/profile-picture`
**Uploads profile picture**
```
Content-Type: multipart/form-data
File field: profilePicture (max 5MB)
Allowed: JPEG, JPG, PNG, GIF
```

#### `GET /api/drivers/profile-picture`
**Gets profile picture URL**
```json
Response:
{
  "success": true,
  "data": {
    "id": "uuid",
    "originalUrl": "http://localhost:3002/uploads/user_uuid/filename.jpg",
    "thumbnailUrl": "http://localhost:3002/uploads/user_uuid/filename_thumbnail.jpg",
    "smallUrl": "http://localhost:3002/uploads/user_uuid/filename_small.jpg",
    "mediumUrl": "http://localhost:3002/uploads/user_uuid/filename_medium.jpg",
    "mimeType": "image/jpeg",
    "size": 1024000,
    "width": 800,
    "height": 600
  }
}
```

#### `DELETE /api/drivers/profile-picture`
**Deletes profile picture**

### **3. Vehicle Management**
#### `POST /api/drivers/vehicles`
**Adds a vehicle**
```json
{
  "type": "small_van",
  "make": "Ford",
  "model": "Transit Connect",
  "year": 2022,
  "color": "White",
  "licensePlate": "ABC123",
  "maxWeight": 800,
  "maxVolume": 4.5,
  "insuranceInfo": "Policy #: INS123456"
}
```

#### `GET /api/drivers/vehicles`
**Lists all vehicles**
```json
Response:
{
  "success": true,
  "data": [
    {
      "id": "vehicle_uuid",
      "driverId": "driver_uuid",
      "type": "small_van",
      "make": "Ford",
      "model": "Transit Connect",
      "year": 2022,
      "color": "White",
      "licensePlate": "ABC123",
      "maxWeight": 800,
      "maxVolume": 4.5,
      "imageUrl": "http://localhost:3002/uploads/vehicles/user_uuid/vehicle_uuid_12345.jpg",
      "isActive": true,
      "currentStatus": "available",
      "insuranceInfo": "Policy #: INS123456"
    }
  ]
}
```

#### `PUT /api/drivers/vehicles/:id`
**Updates a vehicle**
```json
{
  "make": "Mercedes",
  "model": "Sprinter",
  "year": 2023,
  "color": "Blue",
  "currentStatus": "maintenance",
  "isActive": true
}
```

#### `DELETE /api/drivers/vehicles/:id`
**Deletes a vehicle**

### **4. Document Management**
#### `POST /api/drivers/documents`
**Uploads a document**
```
Content-Type: multipart/form-data
Fields:
- document (file, max 5MB)
- type: "license" | "insurance" | "registration" | "inspection" | "background_check"
- name: "Driver's License"
- expiryDate: "2025-12-31" (optional)

Allowed: PDF, DOC, DOCX, JPEG, JPG, PNG
```

#### `GET /api/drivers/documents`
**Lists all documents**
```json
Response:
{
  "success": true,
  "data": [
    {
      "id": "doc_uuid",
      "driverId": "driver_uuid",
      "type": "license",
      "name": "Driver's License",
      "fileName": "license_12345.pdf",
      "fileUrl": "http://localhost:3002/uploads/user_uuid/license_12345.pdf",
      "fileSize": 2048000,
      "mimeType": "application/pdf",
      "status": "approved",
      "uploadDate": "2024-01-15T10:30:00.000Z",
      "expiryDate": "2025-12-31T00:00:00.000Z",
      "verifiedBy": "admin_uuid",
      "verifiedAt": "2024-01-16T14:20:00.000Z"
    }
  ]
}
```

#### `PATCH /api/drivers/documents/:id/status`
**Updates document status (admin)**
```json
{
  "status": "approved",
  "verifiedBy": "admin_uuid",
  "rejectionReason": "Document expired" // if rejected
}
```

### **5. Availability Management**
#### `PUT /api/drivers/availability`
**Updates weekly availability**
```json
[
  {
    "dayOfWeek": 1, // Monday (0=Sunday)
    "startTime": "09:00",
    "endTime": "17:00",
    "isActive": true
  },
  {
    "dayOfWeek": 2, // Tuesday
    "startTime": "10:00",
    "endTime": "18:00",
    "isActive": true
  }
]
```

#### `GET /api/drivers/availability`
**Gets current availability**
```json
Response:
{
  "success": true,
  "data": [
    {
      "id": "availability_uuid",
      "driverId": "driver_uuid",
      "dayOfWeek": 1,
      "startTime": "09:00",
      "endTime": "17:00",
      "isActive": true
    }
  ]
}
```

## 📁 **Database Structure**

### **Tables:**
1. **drivers** - Main driver profiles
2. **profile_pictures** - Profile images with multiple sizes
3. **vehicles** - Driver vehicles with images
4. **documents** - Driver documents (license, insurance, etc.)
5. **driver_availabilities** - Weekly schedule
6. **driver_metrics** - Daily performance metrics
